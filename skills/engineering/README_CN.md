# 工程技能

我每天用于代码工作的技能。

- **[diagnose](./diagnose/SKILL_CN.md)** — 针对严重错误和性能回归的纪律化诊断循环：复现 → 最小化 → 假设 → 检测 → 修复 → 回归测试。
- **[grill-with-docs](./grill-with-docs/SKILL_CN.md)** — 追问环节，根据你的计划挑战现有领域模型，锐化术语，并内联更新 `CONTEXT.md` 和 ADR。
- **[triage](./triage/SKILL_CN.md)** — 通过分类角色状态机对问题进行分类。
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL_CN.md)** — 在代码库中寻找深化机会，参考 `CONTEXT.md` 中的领域语言和 `docs/adr/` 中的决策。
- **[setup-matt-pocock-skills](./setup-matt-pocock-skills/SKILL_CN.md)** — 搭建其他工程技能消耗的单仓库配置（问题跟踪器、分类标签词汇、领域文档布局）。在使用 `to-issues`、`to-prd`、`triage`、`diagnose`、`tdd`、`improve-codebase-architecture` 或 `zoom-out` 之前，每个仓库运行一次。
- **[tdd](./tdd/SKILL_CN.md)** — 测试驱动开发，带有红 - 绿 - 重构循环。一次构建一个垂直切片的功能或修复错误。
- **[to-issues](./to-issues/SKILL_CN.md)** — 使用垂直切片将任何计划、规范或 PRD 分解为可独立获取的 GitHub 问题。
- **[to-prd](./to-prd/SKILL_CN.md)** — 将当前对话上下文转化为 PRD 并将其作为 GitHub 问题提交。无需访谈——只需综合你已经讨论过的内容。
- **[zoom-out](./zoom-out/SKILL_CN.md)** — 告诉 Agent 放大并提供更广泛的上下文或对不熟悉代码部分的更高层次视角。
- **[prototype](./prototype/SKILL_CN.md)** — 构建一次性原型以阐明设计——要么是用于状态/业务逻辑问题的可运行终端应用程序，要么是从一个路由切换的几个截然不同的 UI 变体。
