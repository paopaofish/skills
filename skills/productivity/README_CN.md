# 生产力技能

通用工作流工具，不特定于代码。

- **[caveman](./caveman/SKILL_CN.md)** — 超压缩通信模式。通过删除填充内容同时保持完整的技术准确性，减少约 75% 的 token 使用量。
- **[grill-me](./grill-me/SKILL_CN.md)** — 对计划或设计进行无情访谈，直到决策树的每个分支都得到解决。
- **[handoff](./handoff/SKILL_CN.md)** — 将当前对话压缩成交接文档，以便另一个 Agent 可以继续工作。
- **[teach](./teach/SKILL_CN.md)** — 在多个会话中教授用户新技能或概念，使用当前目录作为有状态的教学工作区。
- **[write-a-skill](./write-a-skill/SKILL_CN.md)** — 创建具有适当结构、渐进式披露和捆绑资源的新技能。
